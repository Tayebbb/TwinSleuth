# Upgrade implementation record

Date: 2026-10-12. This record implements the worthwhile items identified in the sibling research review. It does not change the frozen `v0.1.0-rc.1` release (`da7a9b8d1b4d7e04b18e6cd513a164aa7141d126`), add ML, download models, deploy a service, or claim educational effectiveness.

## Implemented

- Added a small case registry and a second fully validated simulated case: **Conveyor Index Drift**. It has four causes, five public probes, a server-only forecast model, a uniform prior, and a feasible 30-minute optimal policy. The existing PIN-9 case remains available unchanged.
- Generalized deterministic model, validation, scoring, policy, service, and request handling around case-scoped identifiers. The browser receives each case's public catalog but never a hidden truth or an unrun forecast row.
- Expanded the post-lock deterministic debrief with per-observation informativeness, model-consistent remaining causes, first-policy comparison where relevant, and a path-cost lesson. It is calculated only after evaluation from the ledger and solver; it does not affect scoring.
- Added local-only episode list, JSON export, and deletion. Deletion removes the episode, secret, events, and idempotency response rows from the configured SQLite database. Export is deliberately the learner-visible episode plus redacted replay events; it does not export the secret table or future forecasts.
- Hardened Examiner prompting by explicitly delimiting learner justification as untrusted data. Gemini remains optional and advisory; the deterministic Skeptic remains non-generative.
- Corrected the submission brief's stale Anthropic claim to describe the current optional Gemini Examiner.

## Boundaries retained

This remains a local MVP. No accounts, tenant authorization, shared rate limiting, cloud backup, or public hosting were added because unauthenticated opaque episode IDs are not suitable authorization for a public multi-user service. Local deletion cannot erase user-created exports or independently managed backups.
