# 2:30 demo script

## Capture

Run `npm run capture:demo`. It starts the local application with `DEMO_TRUTH=H1`, performs the accepted P1 → P3 → P4 path in Chromium, writes six current screenshots, and saves `submission/twinsleuth-demo.webm`. No service is published and no hosted URL is claimed.

- **0:15–0:40:** “I must commit a forecast for all four possible causes before running a test. Repeating the same motion gives the same predicted result everywhere.”
- **0:40–0:55:** “The LangGraph Skeptic sees only my predictions and revealed evidence. It asks what this retry can eliminate. It never sees hidden truth or the unrun forecast.”
- **0:55–1:20:** “I revise to P3. This forecast splits the four causes two-by-two, so the test runs directly. The server returns the observation and only then reveals the authored row.”
- **1:20–1:40:** “P4 tests the remaining J2-versus-zone ambiguity. The visualization now shows the observed J2 stop at 95 degrees.”
- **1:40–2:10:** “I diagnose H1 and cite evidence once for each cause. Deterministic code—not the LLM—calculates the five-part score.”
- **2:10–2:30:** “The debrief compares my belief path with the evidence-consistent path, checks every claim, compares my 15-minute route with the exact policy branch, and reveals the server-selected fault. The same core flow works without an API key.”

Publishing or hosting is intentionally absent because the standing instruction forbids pushing or creating a remote repository.
