# Submitted demo

The final submission video is [TwinSleuth-Demo.mp4](TwinSleuth-Demo.mp4), a five-minute narrated walkthrough with burned-in captions. Its narration, storyboard, production notes, and caption source are in [`../artifacts/demo-video/`](../artifacts/demo-video/).

For the local deterministic browser-capture preview, run `npm run capture:demo`. It exercises the P1 → P3 → P4 path in Chromium and writes current screenshots plus `submission/twinsleuth-demo.webm`. That short preview is a verification artifact, not the submitted demo.
